Gemini 對話台（Windows 本機版）
================================

和網頁版是同一個對話台，多了「程式代理」：Gemini 可以在你指定的資料夾裡
讀檔、搜尋、修改程式、執行 PowerShell 指令，作法類似 Claude Code。

不需要安裝任何東西（使用 Windows 內建的 PowerShell 與 Edge）。

【安裝】
1. 把整個資料夾解壓縮到固定位置，例如 文件\Gemini-harness
2. 確認資料夾裡有：Start.bat、server.ps1、index.html

【啟動】
1. 按兩下 Start.bat
   - 第一次可能出現「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」
   - 若出現防火牆詢問，選「取消」也可以（只在本機使用，不需要對外開放）
2. 會開出一個獨立的對話台視窗（Edge 應用程式模式）
3. 黑色的啟動視窗要保持開著，關掉它就會停止

【第一次使用】
- 本機版的網址是 http://localhost:8765，和 GitHub 網頁版的設定是分開存的，
  所以要在「設定」重新填一次 API 金鑰（或 Vertex 金鑰）
- 金鑰只存在這台電腦的瀏覽器裡，不會寫進任何檔案

【程式代理】
1. 左側按「程式代理」
2. 上方按「選擇資料夾」選一個工作資料夾（代理只能存取這個資料夾裡的檔案）
3. 輸入任務，例如「執行這個專案，找出錯誤並修好」
4. 核准方式（上方右側）：
   - 每次詢問：修改檔案、執行指令前都會問你（建議）
   - 自動允許修改檔案：改檔不問，執行指令仍會問
   - 全部自動執行：都不問，請只在你信任的任務使用
5. 在工作資料夾放一個 GEMINI.md（或 AGENTS.md / CLAUDE.md），
   寫上專案說明與規則，代理每次開始任務都會先讀

【安全設計】
- 伺服器只接受本機連線，每次啟動都會產生新的權杖，其他網站無法呼叫它
- 檔案操作限制在你選的工作資料夾內
- 執行中按輸入框的停止鍵，會中斷模型並拒絕所有等待中的操作

【疑難排解】
- 視窗閃一下就關掉：用滑鼠右鍵 Start.bat →「編輯」確認內容沒被改動，
  或在資料夾裡按住 Shift + 右鍵 →「在終端機開啟」，輸入
  powershell -ExecutionPolicy Bypass -File .\server.ps1  看錯誤訊息
- 顯示連接埠被占用：關掉其他對話台啟動視窗再試
